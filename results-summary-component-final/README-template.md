### What I learned

Working on this project helped me understand how to use CSS custom properties to manage a consistent colour system across a component. I also learned how to load local fonts using `@font-face` instead of relying on a CDN, and how to use `linear-gradient` for both background panels and inner circle effects.

Using `hsla()` for background tints on the summary rows was a key technique — instead of creating separate colour values, I simply added transparency to the existing primary colours.
